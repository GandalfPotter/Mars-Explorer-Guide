# marsxplr guide

- can be found at [my gitea repository](https://gitea.moe/via256/marsxplr-decomp/releases)<br>
- stable, with fully working multiplayer and worlds<br>
- the OG<br>
- only windows (and wine) supported<br>

## "remastered" W.I.P.
- can be found at [my github repository](https://github.com/via256/unity3d-marsxplr/releases)<br>

- more OS's supported natively<br>
